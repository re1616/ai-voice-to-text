# AI Voice to Text

Бесплатное Android-приложение для записи и расшифровки речи **полностью на телефоне**: без серверов, рекламы, аккаунтов и аналитики. Распознавание выполняет whisper.cpp, ИИ-обработка текста — llama.cpp. Сеть нужна только для скачивания моделей.

## Установка

1. Откройте раздел **Releases** этого репозитория → `latest` и скачайте `AIVoiceToText.apk` на телефон.
2. Откройте файл и разрешите установку из этого источника.
3. При первом запуске выберите модель распознавания (приложение подскажет подходящую под объём ОЗУ).

`AIVoiceToText-offline.apk` — сборка вообще без разрешения на интернет: модели добавляются через импорт файла (`.bin` для Whisper, `.gguf` для LLM).

Требования: Android 8.0+, 64-битный процессор ARMv8.2 (практически все телефоны с 2018 года), 4 ГБ ОЗУ для распознавания, 6–8 ГБ для ИИ-конспектов.

## Возможности

- **Одна кнопка записи** внизу экрана; запись в фоне, пауза, «★ Важно», автопауза при звонке; старт из виджета, плитки и ярлыка.
- **Название и выжимка сами**: после расшифровки заметка получает понятное название и 3 главных тезиса.
- **Спросить у заметок**: вопрос по всем записям («что я обещал на этой неделе?»), ответ с ссылками на фрагменты.
- **Кто говорит**: разметка спикеров (WeSpeaker + кластеризация), имена меняются одним нажатием.
- **Переписать как…**: письмо, сообщение, пост — и сразу «Отправить».
- **Диктовка в буфер**: плитка в шторке → сказал → текст скопирован.
- Живой черновик во время записи и точная перерасшифровка после остановки; Silero VAD, возобновление после перезапуска.
- Импорт аудио и видео через «Поделиться» и «+»; караоке-плеер, скорость, пропуск пауз, запоминание позиции.
- ИИ-действия: очистка, выжимка, задачи-чек-лист, протокол встречи, конспект, свои шаблоны (map-reduce для длинных записей).
- Папки, теги, корзина с отменой, поиск; экспорт MD/TXT/SRT/VTT/JSON, папка для Obsidian, резервная копия.

## Сборка

Сборка выполняется в GitHub Actions (`.github/workflows/build.yml`) при каждом пуше в `main`: готовые APK публикуются в релиз `latest`.

Локально нужны JDK 17, Android SDK (platform 36), NDK `28.2.13676358`, CMake 3.22.1:

```bash
./scripts/fetch-deps.sh          # whisper.cpp v1.9.5 и llama.cpp b11676 в third_party/
python3 scripts/gen_catalog.py   # каталог моделей с SHA-256 и модель Silero VAD в assets/
./gradlew assembleStandardRelease
```

## Устройство

| Модуль | Содержимое |
| --- | --- |
| `whisper` | JNI-обёртка whisper.cpp (распознавание + VAD), статическая сборка ggml |
| `llama` | JNI-обёртка llama.cpp (генерация, шаблоны чата), отдельная копия ggml |
| `app` | Compose UI, SQLite + FTS4, запись, WorkManager-задачи, менеджер моделей, спикеры (ONNX Runtime), экспорт |

Обе нативные библиотеки собираются с выравниванием 16 KB (требование Google Play) и скрывают внутренние символы, поэтому две версии ggml не конфликтуют. В памяти одновременно держится только одна большая модель.
